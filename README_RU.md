# OmGithub OLED — Android WebView

Лёгкая Android-оболочка для открытия https://omgithub.com в отдельном приложении без интерфейса Chrome.

## Что есть
- Android WebView с JavaScript, DOM Storage и cookies для работы современного сайта.
- OLED Black, светлая и системная темы.
- Отдельная иконка приложения.
- Кнопка настроек в верхней панели.
- Кнопка «Назад» возвращает по истории сайта.
- Без сторонних SDK, аналитики и рекламных библиотек.

## Сборка APK
1. Откройте папку проекта в Android Studio (Hedgehog или новее).
2. Дождитесь синхронизации Gradle.
3. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
4. APK появится в `app/build/outputs/apk/debug/`.

## Установка
Перенесите APK на Android, разрешите установку приложений из выбранного источника и установите.

## Важные ограничения
WebView использует системный Android System WebView (тот же движок Chromium), но не запускает полноценный интерфейс Chrome.
Некоторые провайдеры авторизации могут запрещать вход во встроенных браузерах. Если OmGithub или GitHub OAuth блокирует WebView, потребуется открыть соответствующий экран во внешнем браузере.
Сайт должен разрешать работу во встроенном WebView; ограничения со стороны самого сайта приложение обойти не может.


## Автоматическая сборка APK

При каждом push в `main` GitHub Actions собирает debug APK. Готовый файл доступен в разделе Artifacts запуска сборки.
